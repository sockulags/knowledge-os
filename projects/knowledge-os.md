Knowledge OS is a local-first, filesystem-native knowledge store. Markdown records are canonical truth; provenance, validation, indexing, bounded context, and the explicit discovery return path are owned here. Sources and discoveries remain separate trust boundaries, and Agentic Work OS remains responsible for execution and orchestration. The v0.0.1 product excludes background workers, model-driven trust decisions, semantic fact checking, and runtime automation.
