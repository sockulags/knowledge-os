# Discoveries

External-agent observations live here as evidence-bearing Markdown records. A discovery is canonical as an observation, never established knowledge by ingestion or indexing.

The explicit lifecycle is `proposed -> retained | rejected | promoted`.
Retained discoveries must be project-scoped and are eligible only for that
project's context, where they are labeled reviewed observations. Promotion
creates a new draft knowledge/project record with direct discovery provenance
and a promote review target; it never adds duplicate `sources` or `related`
lineage, merges, overwrites, or supersedes an existing record.
